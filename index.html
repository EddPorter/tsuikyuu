Tsuikyuu

Small interactive explainers for algorithms. Each one is a single page you can open, poke at and read the code of.

Explainers

  1. 第1話 Search One loop, many searches Breadth-first, depth-first, Dijkstra, greedy and A* are one search loop with a single function swapped. Paint a map and watch each one run. →
  2. 第2話 Strings Just enough letters The fewest letters that pick out one word from a list. Swap how a search matches, what you are looking for and how matches are counted, and watch the answers and the work change. →
  3. 第3話 Data structures Shared beginnings A tree that stores each shared beginning once. Build one letter by letter, look words up, count what it saves, then squash it into a suffix tree. →
  4. 第4話 Similarity Nearly the same Why an ordinary hash cannot spot near-copies of a message, and how shingles, MinHash and banding find a whole mailing campaign without comparing every pair. →
  5. 第5話 Search Best match first A short query matches dozens of items. See how a fuzzy finder scores each match, picks the best placement of the letters with dynamic programming, and stays quick on thousands of paths. →
  6. 第6話 Dynamic programming What changed? How a diff decides what stayed and what changed. Fill in the longest-common-subsequence grid cell by cell, then allow swaps to get edit distance, and see why big files need shortcuts. →
  7. 第7話 Strings Read it backwards Find a word in a long text by comparing it from its last letter. One mismatch rules out many positions, so most of the text is never looked at. Step through it and measure the skipping. →
  8. 第8話 Dynamic programming The whole paragraph Filling each line as full as possible gives worse paragraphs than choosing every break together. Compare the two, then see the table of small answers that finds the best breaks, as in TeX. →
  9. 第9話 Dynamic programming The most likely story From a week of noisy clues, find the single most likely hidden sequence behind them. Fill the Viterbi grid column by column, and see why guessing each day alone goes wrong. →
  10. 第10話 Estimation How much to believe Combine a prediction with a noisy reading, weighted by how certain each is. Run the Kalman filter on a noisy track, mis-tune it on purpose, then add a hidden speed that it learns from positions alone. →
